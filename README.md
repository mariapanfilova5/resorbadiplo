# РЕСОРБА — Интернет-магазин медицинских товаров

## Запуск

```bash
cd Resoba
dotnet run
```

Приложение запустится на `http://localhost:5011`.  
При первом запуске база данных и тестовые данные создаются автоматически.

## Возможности

- **Каталог** — просмотр, поиск и фильтрация по категориям
- **Карточка товара** — фото, описание, документы
- **Корзина** — добавление, изменение количества, удаление
- **Оформление заказа** — для ФЛ и ЮЛ (с ИНН и названием организации)
- **Избранное** — добавление/удаление, перемещение в корзину
- **Личный кабинет** — история заказов
- **Админ-панель** — управление товарами, категориями, заказами, загрузка документов

## Смена базы данных

Строка подключения в `Resoba/appsettings.json` настроена на `.\SQLEXPRESS`.  
**SSMS**: сервер `.\SQLEXPRESS`, аутентификация Windows, база `ResobaDb`.
